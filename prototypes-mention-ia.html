Six façons de rendre la fabrication visible

Chaque bloc ci-dessous simule le hero du site à taille de lecture réelle. Les deux mentions sont ainsi évaluées en contexte, avec le texte d’introduction, le portrait, son cadre terracotta et la signature de rôles.

Prototype 01

Le colophon discret

Une signature typographique minimale prolonge le texte sans rivaliser avec le message principal. La ponctuation de code et l’étoile éditoriale différencient les deux gestes.

Une préférence possible : le prototype 01

Le colophon discret semble le meilleur point de départ. Il rend les deux mentions lisibles, respecte la hiérarchie actuelle et laisse le portrait comme le manifeste conserver leur rôle principal. Le prototype 05 serait une option plus expressive si l’objectif est de faire de cette transparence un signe visuel distinctif.
